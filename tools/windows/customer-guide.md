# Windows 使用说明

将完整压缩包解压到固定目录，例如 `D:\Apps\ArbitrageDesign`，不要在压缩包预览里直接启动。

## 开启与停止

1. 双击 `开启.cmd`。首次填写数据目录，例如 `D:\ArbData`，必须放在程序目录以外。
2. 填写代理软件实际使用的本机端口，例如 `7890`；输入 `0` 表示直连。以后启动自动复用配置。
3. 程序启动采集和纸上监控，自动打开页面。网页端口被占用时会自动选择空闲端口，请使用启动窗口显示的实际地址。
4. 双击 `停止.cmd`，等待服务全部停止，数据自动保留。关闭浏览器或启动窗口不会停止后台采集。

默认启动不会开启真实交易。完整包自带运行环境，无需另外安装 Python、Node 或 Git。环境缺失时启动脚本会自动下载安装；此时需要网络可用。

## 数据和配置位置

配置保存在 `%LOCALAPPDATA%\ArbitrageDesign\launcher.json`。行情、模拟账本和日志保存在首次选择的数据目录，启动日志位于其中的 `launcher_logs` 文件夹。

修改代理或数据目录：先停止服务，在程序目录的终端运行：

```bat
tools\windows\Arbitrage.cmd configure
```

查看当前服务状态和实际网页地址：

```bat
tools\windows\Arbitrage.cmd status
```

可选的实时辅助页面和实盘管理页面需单独启动：

```bat
tools\windows\Arbitrage.cmd start realtime
tools\windows\Arbitrage.cmd start live
```

启动实盘管理页面只打开管理界面；真实交易仍需要自行填写账户配置并在页面操作。

## 更新和排查

先用旧版本的 `停止.cmd` 确认全部服务停止，再将新版解压到新目录并开启。新版复用原配置和外部数据目录，无需复制或删除历史数据。

若旧程序目录提示正在使用，先关闭停留在该目录的 CMD、PowerShell 和资源管理器窗口，再重试。不要删除仍在采集的数据文件。

网页能打开但数字不更新时，检查平台连接状态、代理和启动日志。纸上监控页面提供服务器校时与行情延迟诊断；校时只在进程内部进行，不修改电脑系统时间。

本包仅包含运行文件及本说明，不包含开发设计文档、研究报告、离线分析脚本或本地历史数据。依赖运行时中的许可证和必要资源保留。`application-manifest.json` 可用于查看随包发布的项目文件清单。
