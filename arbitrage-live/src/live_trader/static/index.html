MetaMask 地址与 Funder

MetaMask 登录地址是私钥派生出的 EOA signer；Funder 是 Polymarket 存放资金的地址。类型 0 时两者相同，类型 3 deposit wallet 时通常不同，但 signer 必须是它的 owner 或已授权 session signer。

私钥

钱包登录请从你实际使用的钱包扩展的账户详情导出对应私钥；只输入本地页面，程序会写入 macOS Keychain。不要发到聊天或截图里，也不要填写助记词。

CLOB 身份配置

先填写 Funder、私钥和签名类型，点击“配置并派生身份”。软件通过 Polymarket CLOB 派生 API 凭据，不再调用 Polygon RPC 猜测账户类型。

Polygon RPC

默认使用 Polygon 当前公开的 https://polygon.drpc.org；只有连接失败或较慢时才换成你自己的 Polygon RPC。

代理

电脑没有代理就留空；只有你本地通过代理访问网络时才填写，例如 http://127.0.0.1:7890。CLOB 身份派生和验证会使用这里填写的代理。

Relayer API 密钥

你截图里的页面用于 Relayer 服务，不是 CLOB 下单身份；本程序不读取它。CLOB 的 L2 凭据会由官方 SDK 根据签名私钥自动派生并写入 Keychain。

单笔下单额度

这是每次 FAK 请求的含手续费预算上限，最低 2.5U；系统不会自动使用账户全部余额。

动态主动成交门槛

门槛取“最低份数”和“本次计划买入份数 × 倍数”中较大的值。价格越低、相同预算能买的份数越多，要求看到的真实主动买入也会相应提高。
