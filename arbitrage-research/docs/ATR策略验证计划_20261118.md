# ATR策略验证计划（T068，2026-11-18）

本轮只做离线回测，不修改纸上交易、实盘、监控或资金配置。ATR先作为波动率/归一化因子，不直接当作涨跌方向。

## 冻结规则

使用T065冻结的3752个官方结算BTC五分钟市场、同一盘口缓存、同一官方标签到达时间和同一成交模型。基础条件仍为剩余270–30秒、卖一0.30–0.50、1U含费预算、300ms延迟、盘口源/接收时间年龄≤2秒、持有官方结算。

|编号|规则|
|---|---|
|A1|M3顺势恢复 + ATR(1m,14)分位数在过去60根ATR的20%–80%之间|
|A2|M3顺势恢复 + ATR分位数≤80%；只过滤最高20%波动|
|A3|M3顺势恢复 + ATR分位数≥20%；只过滤最低20%波动|
|A4|ATR归一化锚定距离达到0.5：`z=log(Spot/本场开盘价)/(ATR1m/Spot)`，z≥0.5做UP，z≤−0.5做DOWN|
|A5|同A4，但z阈值为1.0|
|A6|同A4，但z阈值为1.5|
|A7|ATR突破延续：过去60秒Spot收益/当前ATR1m绝对值≥1.0，方向与收益相同|
|A8|ATR急变后反转：上一根1分钟TR/ATR≥2，当前已收盘K线方向反转|

ATR使用Wilder平滑；1分钟ATR用于短期规则，5分钟ATR只记录作诊断，不把未收盘K线用于判断。A4–A6使用实时收到的Spot价格和已收盘ATR，要求Spot源与接收时间符合原有新鲜度规则。A7/A8都必须等当前1分钟K线收盘后才触发，信号有效60秒。

## 限制

ATR是波动大小，不能单独决定UP/DOWN。ATR过滤可能提高胜率但减少机会，也可能把最有利的快速行情一起过滤。A4–A8依赖Spot覆盖，缺失不补造。1U研究预算不等于实盘最低金额，费用冻结为每份`0.07*p*(1-p)`。所有参数在查看结果前冻结；末20%是历史末段检查，不是完全未接触的未来样本。
